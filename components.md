# Construction Tools Management System - Components

## Frontend
Responsible for the user interface.
- Login Page
- Dashboard
- Project Management
- Machine Management
- Maintenance Management
- Employee Management
- Payment Management

## Backend
Responsible for application logic.
- User Authentication
- Business Logic
- CRUD Operations
- Validation
- Role Management

## Database
Stores application data.
- Users
- Projects
- Machines
- Employees
- Maintenance Records
- Payments

## User Roles

### Owner
- Manage projects
- Register equipment
- Monitor machine status
- Manage payments
- View reports

### Site Engineer
- Allocate machines
- Raise maintenance requests
- Assign maintenance workers
- Update project progress
- Monitor payments
