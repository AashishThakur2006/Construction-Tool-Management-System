# Construction Tools Management System - Minimum Viable Product (MVP)

## Goal
Develop a working prototype that demonstrates the core functionalities of the Construction Tools Management System.

## Core Features

### Authentication
- User Registration
- Login
- Logout

### Dashboard
- Total Projects
- Total Machines
- Total Employees
- Total Maintenance Records
- Total Payments

### Project Module
- Add Project
- Edit Project
- Delete Project
- View Projects

### Machine Module
- Register Machine
- Update Machine Details
- Allocate Machine

### Maintenance Module
- Raise Maintenance Request
- Assign Maintenance Worker
- Update Maintenance Status

### Employee Module
- Add Employee
- Update Employee
- Delete Employee
- Employee Role Management

### Payment Module
- Add Payment
- Update Payment Status

### Search
- Search Projects
- Search Machines
- Search Employees
- Search Payments

## Success Criteria
- Secure login
- CRUD operations working
- Dashboard displaying correct information
- Search and filters working
- Maintenance and payment updates working correctly
