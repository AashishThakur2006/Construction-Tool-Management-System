# Construction Tools Management System - Project Scope

## Project Overview
The Construction Tools Management System is a web-based application designed to help construction companies efficiently manage projects, equipment, employees, maintenance, and payments through a centralized platform.

## In Scope
- User Registration and Login
- Dashboard with project statistics
- Project Management
- Equipment/Machine Management
- Machine Allocation to Projects
- Employee Management
- Maintenance Request Management
- Payment Management
- Search and Filter functionality
- Role-based access for Owner and Site Engineer

## Out of Scope
- GPS Tracking
- IoT-enabled machine monitoring
- Mobile application
- AI-based maintenance prediction
- Third-party accounting software integration

## Target Users
- Owner
- Site Engineer

## Expected Outcome
A centralized system that reduces paperwork, improves resource tracking, and simplifies construction management operations.
